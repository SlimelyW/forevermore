      What happens on every change

      1. BackupThe setting's original state is saved.
      2. Restore pointBefore the first change in a session, a Windows restore point is created (it can ask you first).
      3. ApplyThe setting is written. Risky settings ask twice, with two separate warnings.
      4. RecordThe change is listed on the Changes page.
      5. UndoOn the Changes page, one click on "Restore" returns the setting to its original state. Undo is free in the free version too.

      Not offered

      • Turning off Windows Update completely. Turning Windows Update off completely (disabling its services) is deliberately not offered: it is hard to undo and Windows often turns it back on by itself.
      • Turning off UAC completely. Turning UAC fully off (EnableLUA=0) is intentionally not offered: it breaks Microsoft Store apps and runs every program as administrator.
      • Turning off Defender completely. Only a real-time protection switch exists; it is on by default and turns off after a two-step warning.
      • Unproven promises. A setting with no proven effect is never described as "raises FPS".

      In competitive games, anti-cheat systems (Vanguard, EAC, BattlEye, FACEIT, VAC) may block, or treat as grounds for a ban, tools that disable driver signature enforcement, inject into a game's DLLs or modify the game process.

      Before / After measurement

      Take a 'Before' measurement before applying settings and an 'After' measurement after applying them (and restarting if needed); the app compares the two. Results are stored on this computer only.

      Honest warning: a single measurement is not proof. Results vary with background activity, temperature and the scene. Under the same conditions (same scene, same duration, same open programs), take at least 3 measurements each and compare the averages. Small differences (below 3%) are often measurement noise.

      Why does it show a warning?

      In shortIt changes system settings and its code is not signed yet, so Windows may warn you. That is expected, and you have ways to check it yourself.

      Why it happens

      Forevermore changes system settings (the registry, services, power plan and so on), so some antivirus programs may treat it as suspicious. It also has no code-signing certificate yet, which is why SmartScreen says "unknown publisher". Because it is written in Python and packaged with PyInstaller, small antivirus engines also raise false alarms.

      Being open source does not remove the warning on its own: Windows does not read the code, it looks at the signature and reputation. Open source lets you check for yourself instead of trusting the warning or us.

      Check it yourself

      • The source is on GitHub; read it, or build it yourself.
      • The zip's SHA-256 is listed on the release page; compare it with Get-FileHash Forevermore.zip in PowerShell.
